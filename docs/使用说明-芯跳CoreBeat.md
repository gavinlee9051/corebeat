# 芯跳 CoreBeat · 使用说明（Windows 版 v0.5.0）

> "会呼吸"的系统资源健康小工具：实时资源/温度监控 + 运行软件总览 +
> 防睡眠/防自动锁屏 + 置顶迷你 HUD。纯本地运行，无任何网络上传。

## 一、运行环境
- Windows 11（推荐）/ Windows 10 21H2+，x64
- 需要 **WebView2 运行时**（绝大多数系统随 Edge 自带；缺失时软件会弹窗引导到官方下载页）
- 绿色版：解压到任意文件夹，双击 `CoreBeat.exe` 即可，无需安装

## 二、主界面速览
| 区域 | 内容 |
|---|---|
| 顶部体征卡 | CPU 总占用（环形+逐核柱+频率）、内存、温度、GPU 占用、运行时长 |
| 中部 | 整机负载"心跳波形"（随真实负载呼吸变色） |
| 底部 | 温度仪表盘 / 运行软件列表（可滚动、可搜索）/ 磁盘与网络实时曲线 |
| 标题栏 | Logo（彩蛋入口）、防睡状态、强调色切换、24h 历史、窗口按钮 |

## 三、功能说明
1. **运行软件列表**：按"软件"归并（Chrome 多进程 = 1 行，带 ×N 角标，显示合计 CPU/内存）。
   - 顶部搜索框可过滤；
   - 点任意行 → 详情/「结束软件」（两次点击确认，会关闭该软件全部窗口）；
   - 不可结束 CoreBeat 自身；系统保护进程会提示需管理员。
2. **防睡眠/防自动锁屏**（托盘 →「防睡眠（别让它睡着）」）：
   - ① 仅防睡　② 防睡 + 防熄屏　③ 加强防锁（叠加极低频鼠标微动）
   - 支持倒计时：30 分钟 / 1 小时 / 整夜 8 小时 / 不限时，到期自动还原
   - 退出软件即还原系统设置；标题栏与托盘实时显示剩余时间
   - 诚实边界：Win+L 等**手动**锁屏无法拦截，仅拦截"闲置触发"的睡眠/熄屏/锁屏
3. **置顶迷你 HUD**（托盘 →「置顶迷你 HUD」）：桌面角落心跳小窗。
   - 按住拖动；托盘可调透明度（100/80/60/40%）；双击回主界面
4. **24h 趋势**（标题栏 24h 按钮）：本地留存（`%LOCALAPPDATA%\CoreBeat\history24.csv`），重启不丢。
5. **告警**：任一温度 ≥85℃ 或内存 ≥90% → 右上气泡 + 提示音（同条件 10 分钟不重复）。
6. **温度数据边界**：
   - GPU 温度/占用、CPU 负载、内存、磁盘、网络：普通权限可读
   - **NVMe 温度**：需管理员（托盘 →「以管理员身份重启」出现 UAC 属正常）
   - **CPU 温度**：LibreHardwareMonitor 的 Ring0 驱动在本机（ASUS B660M / i5-12400）无法加载，
     故如实显示"—"（方案允许的降级，其余功能不受影响）
7. **彩蛋**（不影响数据与性能）：
   - 主「恋恋芯跳」：连点标题栏 Logo 5 下 → 波形化作跳动爱心 + 随机台词，25 秒自动还原
   - 副「发不发烫」：连点温度卡数字 3 次 → 俏皮气泡；温度 >85℃ 文案变为"这芯在发烧，建议去吹吹风～"
8. **主题色**：标题栏三个圆点切换 青绿 / 深海蓝 / 心动紫，重启后保持。

## 四、托盘说明
双击托盘图标：显示主窗口。右键菜单：显示/隐藏主窗、防睡眠档位与倒计时、
回放启动动画、以管理员身份重启（解锁 NVMe 温度）、置顶迷你 HUD（含透明度）、
开机自启（默认关）、退出。**关闭主窗口 = 收进托盘**（进程驻留），请用托盘"退出"结束。

## 五、日志
运行日志：`%LOCALAPPDATA%\CoreBeat\corebeat.log`（每 10s 一条采样摘要，便于排查）。

## 六、常见问题
- **界面空白/无法显示**：未装 WebView2 运行时 → 按弹窗提示到官方下载页安装 Evergreen 运行时。
- **CPU 占用与任务管理器不同步**：请确认看的是任务管理器"CPU"行（本软件与 Win11 的
  `% Processor Utility` 同源，会随负载同波段跳动）。
- **进程列表某软件结束不了**：多为系统/管理员进程，先"以管理员身份重启"。
- **杀毒软件提示**：本软件纯本地无网络，无内核驱动；如误报请添加信任。
