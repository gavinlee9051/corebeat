# 芯跳 CoreBeat · Windows 版开发方案 v1.0（已确认）

> 定位：一款"会呼吸"的系统资源健康小工具 —— 实时资源/温度监控 + 进程总览 + 防睡眠防自动锁屏。
> 名字：芯跳 CoreBeat（"芯/心"同音双关，心电图式视觉语言；防睡功能副题"别让它睡着"）。
> 目标平台：Windows 11 x64（主），兼容 Windows 10 21H2+。
> 目标硬件：Intel / AMD CPU，NVIDIA / AMD 独显（含核显），NVMe。
> 技术栈（已确认）：C# .NET 8 + WPF 原生内核 + WebView2 渲染层（重引擎、轻皮肤）。
> 交付形态：绿色版单文件夹，双击即用；可选开机自启。
> 姊妹文档：macOS 版方案见「方案-macOS-芯跳CoreBeat.md」（Swift + SwiftUI 原生，独立代码库）。

## 1. 功能规格 v1

### 1.1 实时资源总览（含温度）
| 模块 | 内容 |
|---|---|
| CPU | 总占用、单核逐核柱、频率、温度（封装/核心，随主板能力） |
| GPU | 占用、显存、温度、频率（NVIDIA/AMD） |
| 内存 | 占用/总量 |
| 磁盘 | 读写速率、NVMe 温度 |
| 网络 | 实时上下行速率曲线 |

- 刷新节奏：数值 1s、曲线 250ms。
- 温度超阈值自动转暖色（青绿→琥珀→绯红随温度渐变）。

### 1.2 正在运行的软件 / 进程
- 列表：应用图标、名称、PID、CPU、内存、线程；支持搜索 + 按 CPU/内存排序，行内动效重排。
- 详情浮层：路径、启动时间、CPU 历史小图；一键结束进程（二次确认，需提权时自动提示）。

### 1.3 防睡眠 / 防自动锁屏（托盘常驻小开关）
| 档位 | 行为 |
|---|---|
| ① 仅防睡 | 阻止系统进入睡眠 |
| ② 防睡 + 防熄屏 | 阻止睡眠与显示器关闭 |
| ③ 加强防锁 | 定时轻动鼠标（微动），杜绝系统因闲置触发自动锁屏 |

- 支持倒计时（30 分钟 / 1 小时 / 整夜 / 自定义），到期自动还原。
- 退出软件即还原系统设置；所有变更状态在托盘可见。
- 诚实边界：Win+L 等手动锁屏无法拦截，仅拦截"闲置触发的休眠/熄屏/锁屏"。

### 1.4 加值项（v1 全含）
- 置顶迷你 HUD：桌面角落"一颗活的心脏"，只留波形 + 三指标，可拖拽 / 调透明度 / 双击回主界面。
- 24h 历史曲线本地留存：重启不丢，可回看趋势。
- 温度/内存异常告警：气泡提醒 + 可选提示音。
- 开机自启：设置开关，默认关闭。

## 2. UI 与动效设计语言
- 视觉：暗色玻璃拟态 + 细腻噪点；主色随温度 青绿→琥珀→绯红 渐变，支持 3 组强调色预设。
- 主界面布局：
  1) 顶部体征栏：总占用环形灯 / 内存 / 温度 / 运行时长；
  2) 中部"心跳波形区"：整机负载心电图（视觉 C 位）；
  3) 瓦片区：温度仪表盘 / 进程榜 / 磁盘与网络 sparkline。
- 招牌动效：
  1) 启动 = 一次心跳脉冲扩散，瓦片弹性 staggered 入场；
  2) 负载升高时波形与环形灯同步"呼吸鼓动"并转暖色；
  3) 数值变化：数字滚动 + 能量条平滑过渡；
  4) 进出托盘、切紧凑模式均带过渡动画。
- 迷你 HUD：低透明度半隐藏，波形持续跳动。

## 3. 小彩蛋（已确认加入）
- 主彩蛋「恋恋芯跳」：在主界面标题区或迷你 HUD 上连点 5 下芯跳 Logo → 心电图波形当场合成为一颗跳动爱心（纯 CSS 动画 + 回弹心跳感），浮现一句随机暖心台词（例："这颗芯，为你 24/7 保持清醒"），约 25 秒后自动还原。
- 副彩蛋「发不发烫」：在 CPU 温度卡上连点 3 次 → 弹出俏皮气泡；温度 >85℃ 时文案换为"这芯在发烧，建议去吹吹风～"。
- 彩蛋不影响数据与性能；托盘菜单提供关闭入口。

## 4. 温度传感器策略与权限
- 采集：引用 LibreHardwareMonitorLib（开源、活跃维护，覆盖主流 CPU/GPU/NVMe）。
- 权限：默认普通权限启动；检测到传感器不可读时顶部提示"以管理员身份重启以解锁全部温度"，支持一键重启提权（可关）。
- 降级：读不到即显示"—"，不影响其余功能；单传感器失败绝不让应用崩溃。

## 5. 防睡眠/防锁实现要点
- C# 调用 Win32 SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED | ES_DISPLAY_REQUIRED)。
- 加强档叠加 SendInput 极低频微动（对正常使用无感）。
- 若采用 powercfg 修改电源策略：先备份、退出还原。

## 6. 架构与技术要点
- WPF 单窗口：无边框、自绘标题栏、DWM 圆角/亚克力；内嵌 WebView2 渲染 UI。
- IPC：原生采集 → JSON 推送桥 → WebView2 前端渲染；采集线程与 UI 线程解耦。
- 进程图标：SHGetFileInfo / IShellItemImageFactory 获取高清图标。
- 数据流：采样线程（250ms~1s）→ 滚动缓冲 → 主界面 / HUD / 历史落盘。
- 内存预算 < 120MB；空闲 CPU 占用 < 1%。
- 打包：.NET 自包含发布；WebView2 运行时检测，缺失时一次性引导安装。

## 8. 风险与对策
- 个别主板/笔记本读不到 CPU 温度 → 分层降级 + 提示，不崩溃。
- LibreHardwareMonitor 对最新 CPU 支持滞后 → 保留可切换 nightly 的升级入口。
- WebView2 缺失 → 一次性引导安装。

## 9. 非目标（v2 候选）
